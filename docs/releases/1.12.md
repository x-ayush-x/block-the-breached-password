# 1.12.0 — Present with clear cues

Date: 2026-10-06. Baseline: v1.11. Publication: v1.12 release branch; merge and deployment are separate steps.
Application: 1.12.0. Policy: `hello-world-1.5`. Dashboard schema: `hello-world-report-1`.

## Problem and outcome

The full walkthrough competed with page content during a demo. An optional compact cue panel now carries the selected step between pages, with short actions and expandable talking points. It is manual guidance, not evidence tracking.

## Added / changed

- Activate cues from the existing Demo guide; Previous/Next select steps without requests or automatic navigation.
- Page action links, explicit source labels, talking-point disclosure and End presentation.
- Initial cue-heading focus and same-page heading focus without remounting input state. Heading tabindex is -1, so it adds no ordinary Tab stop.
- End presentation restores focus to the guide toggle and leaves page input state alone.
- Readiness snapshot timestamp and recheck reminder; no reachability claim.
- Rewritten demo script with honest conditional wording for live, mock, failed and incomplete results.
- README, changelog, migration guide and version labels updated. No capabilities removed.

## Security / compatibility

Cues and selected steps stay in React memory, persist only between routes in the same session, and reset on reload. No storage, analytics, automatic checks or new dependencies. Source switching still clears/remounts signup/reset/dashboard. Navigating away still cancels and discards page-local work. Ending cues is not navigation and does not clear a form.

No policy/report schema changes. Services, hooks, hashing, parsing and submit-time protection unchanged. Pages workflow/base path/CSP unchanged. Auth remains simulated.
