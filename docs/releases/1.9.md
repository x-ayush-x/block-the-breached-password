# 1.9.0 — Understand the Security Test Lab

Date: 2026-10-05. Baseline: v1.8. Publication: v1.9 release branch; merge and deployment are separate steps.
Application: 1.9.0. Policy: `hello-world-1.5`. Dashboard schema: `hello-world-report-1`.

## Problem and outcome

The Lab asked beginners to interpret nine dense cards at once. It now explains one selected situation, what response is simulated, what decision is expected and what the actual shared engine decided. A PASS explicitly means correct behavior, including correctly blocking a password.

## Added / changed

- Nine selectable scenario rows with the latest run status, plus a focused detail panel.
- Scenario-specific explanations of strong-but-breached inputs, clear results, common/short passwords, outages, rate limits, malformed responses, timeouts and padding.
- Technical evidence behind a keyboard-accessible native disclosure.
- Full-suite controls with completed, failed and unfinished counts and explicit export scope.
- Browsing keeps current evidence. New runs replace it. Leaving the Lab cancels and discards its run.
- README, release notes, version labels and regression coverage updated.

## Fixed / removed

Lab export version now comes from package.json. The old hard-coded 1.5.0 value was misleading. The redundant summary cards and nine expanded cards were replaced; no engine scenario, export or cancellation capability was removed.

## Security / compatibility

The scenario engine and fixtures are unchanged, apart from export version metadata. No live requests are added. No new dependencies, password storage or analytics. Auth remains simulated. Hashing, HIBP request behavior, policy, stale-response guards and source switching remain unchanged. Pages workflow/base path/CSP unchanged.

Lab export fields remain the same; version now identifies the exporting application. Lab evidence is not accepted by the dashboard comparison tool. Dashboard policy/schema versions stay unchanged.

- `npm run build:pages`: passed. Repository asset base and production CSP checked; restored the standard build for local preview.

## Migration / limitations

Use the complete ZIP or apply the update-only ZIP to v1.8. See [macOS instructions](../UPGRADE-1.9-MACOS.md). No deletions required; back up the previous project first.

The Lab is not a live HIBP capture or production-authentication proof. The 60 ms timeout belongs to its local fixture, not the normal live timeout. Native print dialogs and a full assistive-technology audit remain outside automated coverage. The deferred zxcvbn chunk-size advisory remains.
